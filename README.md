# JoshuaMeyerDA8Repo
Hi everyone! This is my repo for DA8 and I enjoyed this class as well as the project that DA8 it was so much fun and a lot of work but definitely worth it. 

1. What the project does
   - This project is a project that uses the pitches from the past semester of the investment club and looks back at the data of the specific stock, it speficially looks at the percent change of the stock and then that data is used to predict if that specific stock will go up in the next 5 days, and then my picks are put into a fake portfolio equally weighted and then compares that to the S&P 500. 
1. Why the project is useful
   - This project can be useful for portfolio managers as well as people in the investment club as people who are intrested in the stock screeners that I used as well as metrics that I used in the screeners and to predict future prices this could be a hedge fund quant project on the side.
